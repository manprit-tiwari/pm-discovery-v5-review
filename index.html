Foodbridge Module Product Management — Discovery v6 (Finished Goods workspace, in progress)

v6 (Addendum 007): Products and Product detail are the new operational workspace — Find → Select → Act → Impact → Confirm. Every other screen is still the v5 baseline (locked in versions/v5/). Try: filter → “Select all N results” → Bulk Action → Change selling price → Preview → Apply → Undo; the Needs Attention chips; Bulk Actions with nothing selected (selection methods); a row’s ⋮ menu; / and ? for shortcuts.

Every screen below is a hand port of the module's React components, mounted the way the host (storefront-frontend) mounts them, driven by the module's own mock API client and the sandbox's seed data. The design notes live in the private module repo (Addendum 006).

Discovery controls

Each screen has a small “Discovery controls (not module UI)” tab on its left edge. It sets the host inputs the module reads — currency, appProp.supportedUnitIndexLevel / priceCalculationUnitIndex, globalSetting…zohoSyncEnabled — and seed scenarios the sandbox seed never produces (catalogues with customers, Zoho sync outcomes). Defaults match the sandbox.
