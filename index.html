Discovery controls

Each screen has a small “Discovery controls (not module UI)” tab on its left edge. It sets the host inputs the module reads — currency, appProp.supportedUnitIndexLevel / priceCalculationUnitIndex, globalSetting…zohoSyncEnabled — and seed scenarios the sandbox seed never produces (catalogues with customers, Zoho sync outcomes). Defaults match the sandbox.
